# Lab computer checklist

About 10 minutes. Use the same computer, screen and mouse as the study.

1. Unzip the `MemoryTask-Windows` folder somewhere the account can write to, such as the Desktop.
2. Double-click `MemoryTask.exe`. If Windows SmartScreen appears, choose **More info**, then **Run anyway**. If the lab blocks it, ask IT to allow it.
3. Type participant number `999`, then press Enter.
4. Complete the practice, pressing Space, and then one full room.
5. Quit with **Ctrl+Shift+Q** during the second room.
6. Reopen it, type `999`, press **F8** to resume, and finish.
7. Open `data\P999_results.csv` and confirm it has 30 rows.
8. Delete every `P999_` file from `data`.

## Check while it runs

- [ ] The picture fills the screen, without stretching.
- [ ] Objects pick up and drop exactly under the pointer.
- [ ] The blink looks instant, and the 3-second transition plays smoothly.
- [ ] No screen ever shows a condition letter or noise name.

Send back: anything that failed, the Windows version, and the screen resolution.
